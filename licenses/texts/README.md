# Vendored license texts

Texts that `notices.ini` adds to `Third-Party-Notices.txt` because no
package in the build carries them. Each is a verbatim copy of the source
named here.

| File | Source |
| --- | --- |
| `Apache-2.0.txt` | https://www.apache.org/licenses/LICENSE-2.0.txt |
| `ECWolf-copyright` | `docs/copyright` in https://github.com/libretro/ecwolf |
| `ECWolf-license-id.txt` | `docs/license-id.txt` in https://github.com/libretro/ecwolf |
| `GNU-FreeFont-license.txt` | the license record (name ID 13) of the shipped `FreeSansBold.ttf` |
| `GPL-2.0.txt` | https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt (identical to `LICENSE`) |
| `OFL-1.1.txt` | `OFL.txt` in https://github.com/impallari/Cabin, without its copyright header |
| `PrBoom-AUTHORS` | `AUTHORS` in https://github.com/DrUm78/libretro-prboom |
| `Ralph-4-LICENSE.txt` | `LICENSE.txt` in https://github.com/pubby/Ralph-4 |
| `gcc-10.2.0-COPYING.RUNTIME` | `COPYING.RUNTIME` at tag `releases/gcc-10.2.0` of GCC |
| `gcc-10.2.0-COPYING3` | `COPYING3` at tag `releases/gcc-10.2.0` of GCC (the GPL-3.0 text) |
| `musl-1.2.1-COPYRIGHT` | `COPYRIGHT` at tag `v1.2.1` of https://git.musl-libc.org/cgit/musl |
